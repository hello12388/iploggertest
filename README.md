# Iploggertest

Create a simple, modern, dark-themed IP Receiver Dashboard.

IMPORTANT: This is only a temporary testing project. Keep everything extremely simple.

Main Goal

I want my Roblox Lua script to send an HTTP request to my website, and I want the website to display the received IP address.

UI Design

Dark theme with a modern dashboard layout.

A large card showing the latest received IP.

Display whether the IP is IPv4 or IPv6.

Show the time the request was received.

A small request counter.

A clear status indicator: Connected / Waiting for data.

Functionality

Create a simple HTTP API endpoint that accepts requests from my Roblox test script.

Receive the IP address supplied by the request.

Display the received IP on the dashboard.

Automatically update the dashboard when a new request arrives.

Show a message when no data has been received yet.

Restrictions

No key system.

No user management.

No VPN detection.

No ban system.

No Supabase.

No database.

No login system.

No complicated backend architecture.

This is only a temporary IP receiving and display test. Keep the implementation minimal.

Final Requirement

Provide the API endpoint URL and an example HTTP request that I can use in my Roblox Lua script to test the connection.
